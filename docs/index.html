Kioku

Persistent, local-first memory for Claude Code, Codex, OpenCode, and other MCP clients, backed by readable Markdown and typed YAML frontmatter in Obsidian.

Get started View on GitHub

What Kioku provides

Multi-agent handoff

Persist project context, plans, decisions, bugs, and session ownership across fresh agent sessions.

Hybrid retrieval

Combine indexed full-text search with optional local Ollama embeddings and reciprocal rank fusion.

Safe vault mutations

Keep writes inside the configured vault and preserve typed custom frontmatter.

Stable MCP contracts

Generate schemas, annotations, prompts, resources, and profile inventories from live protocol discovery.

Two transports

Use local stdio or authenticated Streamable HTTP with secure loopback defaults.

Optional Obsidian bridge

Open notes, run approved commands, and integrate supported plugins through an authenticated WebSocket bridge.
