# Metodo Zettelkasten

Sistema de notas interconectadas de Niklas Luhmann: cada nota contiene una sola idea,
escrita con mis propias palabras, y se enlaza explicitamente con las notas relacionadas.
El valor no esta en las notas sueltas sino en la red que forman con el tiempo.

Reglas practicas: titulos que sean afirmaciones, enlaces con contexto (por que conecto
esto), y revisar notas viejas al crear nuevas.
