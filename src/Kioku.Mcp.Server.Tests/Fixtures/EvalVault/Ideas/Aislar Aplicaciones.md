# Aislar aplicaciones

Idea recurrente: empaquetar cada aplicacion con todas sus dependencias en un entorno
aislado y reproducible, de modo que se comporte igual en mi maquina, en el servidor de
pruebas y en produccion. Definir la infraestructura como texto versionado y poder
levantar o destruir el entorno completo con un solo comando.

Esto elimina el clasico "en mi maquina funciona" y hace trivial volver a una version
anterior cuando algo sale mal.
