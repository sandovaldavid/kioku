# Adiestramiento de perros

Notas del curso de adiestramiento canino: el entrenamiento con refuerzo positivo funciona
mejor que el castigo. Sesiones cortas de cinco minutos varias veces al dia, premios
pequenos e inmediatos, y terminar siempre con un ejercicio que el perro ya domina.

La consistencia de toda la familia importa mas que la tecnica exacta.
