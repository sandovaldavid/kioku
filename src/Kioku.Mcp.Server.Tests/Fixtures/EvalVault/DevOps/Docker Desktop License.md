# Docker Desktop license

Notes on the Docker Desktop licensing change: free for small companies, paid subscription
required above 250 employees or 10 million revenue. Alternatives if the license becomes a
problem: Podman, Colima on macOS, or plain Docker Engine inside a Linux VM.

This note is about licensing and pricing only, not about how to deploy anything.
