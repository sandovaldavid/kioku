# Incendios forestales

Despues de un incendio, el bosque quemado inicia un proceso de recuperacion que puede
tomar decadas. El suelo agotado pierde nutrientes y la primera vegetacion en volver son
especies pioneras resistentes al fuego. Algunos pinos incluso necesitan el calor del
fuego para abrir sus conos y liberar semillas.

La regeneracion natural suele ser mas robusta que la reforestacion apresurada con
especies foraneas.
