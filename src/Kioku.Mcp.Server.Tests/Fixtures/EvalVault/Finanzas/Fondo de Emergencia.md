# Fondo de emergencia

Meta: seis meses de gastos basicos en una cuenta liquida separada. El fondo de emergencia
no es una inversion; su unico trabajo es existir cuando algo se rompe: salud, trabajo,
casa. Se repone con prioridad absoluta despues de usarlo.

Regla personal: si dudo si algo es una emergencia, no lo es.
