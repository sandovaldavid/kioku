# Home server setup

Self-hosted home server on a mini PC: media server, network-wide ad blocking, file sync,
and automatic backups to an external drive plus one encrypted copy offsite. Everything
runs in containers managed with Docker Compose, one directory per service.

Next steps: monitoring with alerts to my phone, and a UPS so the disks survive power cuts.
