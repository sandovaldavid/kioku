# Garden automation

Automatic watering system for the balcony plants: a small pump, a moisture sensor per
pot, and a microcontroller that waters only when the soil is actually dry. Schedule as
fallback, sensor as primary signal.

Parts list drafted; still need to waterproof the electronics box before summer.
