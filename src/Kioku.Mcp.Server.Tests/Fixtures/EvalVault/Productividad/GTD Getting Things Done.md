# GTD — Getting Things Done

Sistema de David Allen: capturar todo en una bandeja de entrada, procesarla a cero
regularmente, decidir la siguiente accion concreta de cada asunto y revisar el sistema
completo una vez por semana. La revision semanal (weekly review del inbox) es la pieza que
mantiene vivo todo lo demas.

Lo que me llevo: la mente es para tener ideas, no para almacenarlas.
