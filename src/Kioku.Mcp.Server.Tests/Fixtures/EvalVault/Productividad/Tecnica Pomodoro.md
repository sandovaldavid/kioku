# Tecnica Pomodoro

Trabajar en bloques de tiempo de veinticinco minutos con descansos de cinco. Cada cuatro
bloques, un descanso largo. La tecnica funciona porque convierte la concentracion en un
juego con reglas claras y hace visible cuanta atencion real tiene un dia.

Mi adaptacion: bloques de cuarenta minutos para trabajo profundo y pomodoros clasicos
para tareas administrativas.
