# Ceviche clasico

Receta peruana de ceviche: pescado blanco fresco cortado en cubos, jugo de limon recien
exprimido, cebolla roja en pluma, aji limo, cilantro y sal. Marinar solo diez minutos;
el limon cocina el pescado. Servir con camote, choclo y cancha serrana.

El secreto esta en la leche de tigre: licuar un poco del jugo con apio, jengibre y un
trozo de pescado, y devolverla al plato.
