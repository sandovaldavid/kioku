# Pan casero

Formula base: 500 g de harina, 350 g de agua, 10 g de sal, 3 g de levadura seca.
Amasado minimo con pliegues cada media hora, fermentacion lenta en la nevera toda la
noche, y horneado con vapor los primeros quince minutos para una corteza crujiente.

Anotar cada intento: hidratacion, tiempos y temperatura, para ajustar la receta.
