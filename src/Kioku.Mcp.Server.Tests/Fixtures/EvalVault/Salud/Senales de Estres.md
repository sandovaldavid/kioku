# Senales de estres

El estres sostenido se manifiesta antes de llegar al agotamiento total. Senales tempranas:
tension muscular en cuello y hombros, problemas digestivos, insomnio y despertares nocturnos,
y respuestas desproporcionadas ante problemas pequenos del trabajo.

Cuando varias senales aparecen juntas durante semanas, es momento de reducir la carga
y revisar prioridades antes de que el cuerpo pase la factura.
